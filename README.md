# Next-Best-Product Recommendation: Hotel Cluster Prediction

Next-best-product recommendation for travel (Expedia Hotel Recommendations). Given a user's booking history and the search query context, the model ranks hotel clusters and returns a top-20 list per user.

## Approach

- **Main model: SMLP4Rec** (MLP4Rec on RecBole) with a **query embedding** (search context fields encoded as a code) and a **sameDest** component (re-visit signal for the same destination). Two rankings are merged by probability (`m2_merge`) into one top-20 per user.
- **Baselines:** ItemKNN (cosine item-item) and global popularity.
- **Evaluation:** time-based split (test window 2014-11-01 to 2014-12-31), user-level metrics on a fixed top-20 per user, all 222,428 test users, paired user-level bootstrap. Protocol: [`docs/eval_protocol.md`](docs/eval_protocol.md).

## Setup

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```

SMLP4Rec runs on RecBole 1.0.1, which needs numpy 1.23 and pandas 1.5, so use a separate Python 3.11 venv at a short path (long Windows paths break torch DLL loading). Patches: `weights_only=False` in `torch.load`; anomaly detection off.

## Reproduce

```bash
python scripts/download.py                     # raw data into data/raw/ (Kaggle token)
python scripts/expedia_build_bookings.py       # cleaned bookings
python scripts/expedia_build_split.py          # date split
python scripts/expedia_to_recbole.py           # RecBole interactions
python scripts/expedia_query_to_recbole.py     # query-embedding codes
python scripts/run_smlprec_expedia.py          # train SMLP4Rec
python scripts/eval_user_top20.py              # user-level top-20 evaluation
python scripts/bootstrap_user_top20.py         # confidence intervals (metrics land in results/)
pytest
```
