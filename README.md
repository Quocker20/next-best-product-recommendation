# Next-Best-Product Recommendation: Hotel Cluster Prediction

Next-best-product recommendation for travel, built on the Expedia Hotel Recommendations data (Kaggle). Given a user's booking history and the context of their search, the system ranks the 100 hotel clusters (a proxy for room category or package) and returns a top-20 list per user. The main model is SMLP4Rec, an all-MLP sequential recommender, extended with a query embedding of the current search and a same-destination re-visit signal. It is compared with a history-only SMLP4Rec ablation and two baselines (ItemKNN, global popularity) under a strict date-based split and a user-level evaluation with paired bootstrap intervals.

## Approach

- **Main model:** SMLP4Rec (MLP4Rec architecture, RecBole) plus
  - a **query embedding**: the 14 fields of the current search are encoded as a code and enter the model as one extra sequence position;
  - a **sameDest** component: a post-hoc fusion `log q_model + w * log q_sameDest` that boosts clusters the user already booked at the searched destination.
- **Ablation:** plain SMLP4Rec (booking history only), to isolate the gain of the query embedding and of sameDest.
- **Baselines:** ItemKNN (cosine item-item) and global popularity.
- **Split:** by booking time. Train before 2014-09-01, valid 2014-09-01 to 2014-10-31, test 2014-11-01 to 2014-12-31. The test window holds 378,788 bookings of 222,428 users, reported for all, warm (has history) and cold (no history) users.
- **Evaluation:** each test user gets one fixed top-20 list built from two prediction steps and merged by probability (`m2_merge`). Recall@K and NDCG@K are computed against the set of clusters the user books in the test window. Early stopping and model selection use an autoregressive validation score. Differences are tested with a paired user-level bootstrap. Full protocol: [`docs/eval_protocol.md`](docs/eval_protocol.md).

## Setup

Two virtual environments are used because SMLP4Rec runs on RecBole 1.0.1, which pins old numpy and pandas.

**Main venv (`.venv`)**: data build, baselines, comparison, bootstrap, tests.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\Activate.ps1
pip install -e ".[dev,eda]"        # eda: plotting libs for notebooks/expedia_eda.ipynb
python -m ipykernel install --user --name nbp --display-name nbp
```

**RecBole venv**: training and scoring of the SMLP4Rec models. Python 3.11 with numpy 1.23.5, pandas 1.5.3, scipy 1.10.1, CPU torch, and a RecBole 1.0.1 / MLP4Rec clone installed with `pip install --no-deps -e`. Use a short path for this venv, since long Windows paths break torch DLL loading. Two small patches are applied to the RecBole clone: `weights_only=False` in `torch.load`, and anomaly detection off. Install this project into it as well and register its kernel:

```bash
pip install --no-deps -e .
python -m ipykernel install --user --name smlp4rec --display-name smlp4rec
```

Scripts and notebooks do not modify `sys.path`, so `nbp` must be installed in whichever environment or kernel runs them.

## Reproduce

Run from the repository root. "Main" is the `.venv`, "RecBole" is the second venv.

| Step | Command or notebook | Environment |
|---|---|---|
| 1 | `python scripts/fetch_smlp4rec.py` (writes `src/nbp/models/smlprec.py`) | any |
| 2 | `python scripts/download.py` (raw data into `data/raw/`; needs a Kaggle token and accepted competition rules) | main |
| 3 | `python scripts/build_bookings.py` | main |
| 4 | `python scripts/build_query_codes.py` | main |
| 5 | `python scripts/build_split.py` | main |
| 6 | `notebooks/smlp4rec/00_min_delta_calibration.ipynb` (optional; sets `min_delta` in `configs/train.yaml`) | kernel `smlp4rec` |
| 7 | `notebooks/smlp4rec/01_plain.ipynb` | kernel `smlp4rec` |
| 8 | `notebooks/smlp4rec/02_query_samedest.ipynb` (main model) | kernel `smlp4rec` |
| 9 | `notebooks/smlp4rec/03_baselines.ipynb` | kernel `nbp` |
| 10 | `notebooks/smlp4rec/04_compare.ipynb` | kernel `nbp` |
| 11 | `python scripts/eval_user_top20.py baselines`, then `smlp`, then `report` | main, RecBole, main |
| 12 | `python scripts/bootstrap_user_top20.py` | main |

Results go to `results/`, trained checkpoints to `experiments/`, intermediate arrays to `data/interim/` and `data/processed/`.
